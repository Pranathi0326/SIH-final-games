

## Workflow
This project is a digital educational gaming website designed for students and teachers. It features interactive STEM games, assignments, and a smart AI chatbot for instant help with Science, Technology, Engineering, and Mathematics topics. The platform supports grade-appropriate content, multilingual access, and real-time chat. Teachers can manage activities and customize learning, while students can explore games and get tailored explanations. The tech stack includes React, TypeScript, Vite, Tailwind CSS, and shadcn-ui.
